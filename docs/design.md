# Particle field

首页由一个持续存在的粒子光场串起四个场景：名字、开源、文字、本人。原生滚动驱动同一组粒子变形和移动。

## 视觉

- 主色：钴蓝 `#244cff`。
- 浅底：`#f0f1f4`；开源场景深底：`#101727`；文字场景：`#e8edf7`。
- 主文字：浅色 `#15171b`，深色 `#edf1f9`。拉丁字使用 Manrope Variable，中文使用系统字体。
- `over` 与 `true.` 分别位于粒子前后，Chris An 独立显示在首屏。
- 项目名称直接成为交互入口；选中时位移、景深和光场朝向一起改变。
- 底部导航是一条章节刻度，游标连续跟随滚动进度。
- 文章按年份、标题排列，点击进入独立阅读页。
- 联系页将姓名、介绍和邮箱左对齐；彩色头像保持正向。
- 首屏字母随滚动收拢为一个小型字母立方体，沿页面右侧跟随；末段逐字展开成底部低透明度的 OVERTRUE，下半截裁切在页面边缘。

## 动效和交互

四组对应的参数曲面通过顶点着色器连续变形。桌面使用 21,600 个粒子，手机使用 11,700 个；光点直接由着色器绘制，没有位图贴图。稀疏线条连接曲面的部分横截面。

鼠标附近的粒子在屏幕空间局部散开、变亮，移开后聚回。鼠标位置和强度采用阻尼插值，跨过文字、链接时不会突然归零。拖动、方向键、Home 和双击可以旋转或复位光场。暂停按钮只有图标，屏幕阅读器有完整名称。

字母使用同一组可见节点完成全程变形，位置依据首尾真实排版测量，随滚动可逆。中段以八个字母作为立方体顶点，大小写在收拢时交叉淡化。无脚本或减少动态效果时保留静态首屏与底部文字。

使用原生锚点与滚动；桌面轻量 proximity snap，手机不吸附。减少动态效果时默认暂停，去掉进入动画和滚动过渡；标签页隐藏时停止渲染。WebGL 不可用或上下文丢失时显示静态回退。无 JavaScript 时所有项目顺序展开。

## Logo

开环与圆点作为统一标识。网站页眉与 favicon 使用透明彩色版，深色主题与开源场景使用白色标识。素材另保留方形、透明纯黑、透明纯白版本。SVG 可缩放，PNG 为 1024 × 1024。素材在 `public/brand/`，网站标识为 `public/brand/mark-color.svg`；个人仓库 `overtrue/overtrue` 保存了原始 `logo.svg` 与 `brand/`。

## 内容边界

只使用已核实的公开介绍和项目角色，不放未经核实的统计数字、雇主或头衔。29 篇旧文章继续作为可搜索、可访问的独立页面，原站文件保留在 `legacy/`。

## 阅读页

归档、文章和 404 共用透明标识、数字导航、Manrope 字体和半截页脚字标。归档按年份分组，搜索保留本地执行。文章使用窄正文与右侧目录；手机上目录折叠到正文前。阅读进度显示在页面顶边。

代码在构建时由 Shiki 高亮，兼容原文的 `php?start_inline=1` 和 Shell 标签；未知语言按纯文本显示。代码块带语言、行数和复制按钮，长代码与表格独立滚动。高亮和原生目录链接不依赖 JavaScript。

## 主题与语言

页眉提供浅色、深色、跟随系统三种选择，默认跟随系统。选择在本机保存，跨页面和刷新保留；初始主题在首屏绘制前读取。文字、分隔线、表格、标识、粒子颜色随主题调整，彩色头像保持原样。禁用脚本时仍跟随系统配色。

中文为默认界面，EN / 中按钮切换个人介绍、项目说明、导航和阅读工具文案，并记住选择。29 篇博客的标题、正文、目录标题和代码不翻译；界面译文集中在 `src/lib/i18n.ts`。
